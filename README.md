# Dessert Menu Demo

This is a responsive, elegant dessert menu demo built with **HTML5** and **CSS3**.

## Features
- Fully responsive layout (works on mobile, tablet, and desktop)
- Modern minimalistic design with pastel accents
- Hover effects on menu cards
- Easy to edit text, prices, and images

## How to edit
- **Change menu items or prices:** Open `index.html` and update the `<h3>` and `<p>` tags inside `.menu-item` divs.
- **Change images:** Replace files in the `images/` folder.
- **Change styles:** Open `style.css` and update colors, fonts, spacing, etc.
